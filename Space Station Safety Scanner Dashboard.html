System Architecture
Server-Side Inference Pipeline
📱 Client Layer
React Native + Expo | Camera API | Image Picker | SVG Overlays
↓ POST /detect (image) ↓
🌐 API Gateway
FastAPI | Uvicorn Server | Async Request Handling | Input Validation
↓ Process Image ↓
🧠 Inference
YOLOv8 | PyTorch | MPS/CUDA/CPU | Real-time Bounding Boxes
↓ JSON Response ↓
📊 Response
Bounding Boxes | Class Labels | Confidence Scores | Metadata
✨
Why Server-Side Inference?

🚀 Hackathon Speed

Fastest to implement - no app compilation/deployment needed

🔄 Model Updates

Update model without redeploying app - instant improvements

✅ Consistency

Same results across all devices - no version fragmentation

📈 Scalability

Easy to scale backend - add more compute as needed

End-to-End App Workflow
From capture to detection to result
1
📸 User Opens App
Launch mobile app, request camera permissions
2
📷 Capture or Upload
Take live photo or select from gallery
3
⚙️ Adjust Settings
Set confidence threshold, select detection mode
4
📤 Send to Server
POST request with image to FastAPI /detect endpoint
5
🧠 Run Inference
YOLOv8 processes image, generates bounding boxes
6
📊 Receive Results
JSON response: boxes, classes, confidence scores
7
🎨 Render Overlays
SVG bounding boxes + labels on image
8
💾 Save & Export
Save result, export as image/PDF, flag if needed
